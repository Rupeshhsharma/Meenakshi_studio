## Overview

Meenakshi Studio is a website development project created to present the business online through a structured, visually appealing, and easy-to-navigate interface.

The project focuses on website presentation, organized content, and maintainable frontend code. Its structure provides a foundation for ongoing website updates and future enhancements as business requirements evolve.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Git
- A modern web browser
- Visual Studio Code or another code editor (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/Rupeshhsharma/Meenakshi_studio.git
```

### 2. Navigate to the Project

```bash
cd Meenakshi_studio
```

### 3. Open the Website

Open `index.html` in your preferred web browser.

For local development, you can use the Live Server extension in Visual Studio Code.

## Maintenance and Updates

For future updates and maintenance:

- Keep website content and images organized.
- Test changes in a local environment before deployment.
- Verify image paths and stylesheet references after modifications.
- Test the website across supported browsers and screen sizes.
- Maintain backups of the production version before significant changes.
- Keep credentials, private configuration, and sensitive information out of the public repository.
